# Backend

API на NestJS: агенты, навыки, процессы, запуски и токен Cursor.

Токен не возвращается в браузер целиком. Режим подключения Cursor (CLI или API) хранится на сервере и меняется в настройках; по умолчанию CLI (`agent -p --trust --workspace …` в папке проекта). API вызывает Cloud Agents при сохранённом токене. `CURSOR_LIVE=0` отключает живой вызов. Список проектов — `GET/POST /api/projects`. Как запускать оба приложения — в README корня.
