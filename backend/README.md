# Backend

API на NestJS: агенты, навыки, процессы, запуски и токен Cursor.

Токен не возвращается в браузер целиком. Шаги со средой Cursor вызывают Cloud Agents API при сохранённом токене; `CURSOR_LIVE=0` отключает вызов. Список проектов — `GET/POST /api/projects`. Как запускать оба приложения — в README корня.
