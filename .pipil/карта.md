# Карта

Пипил — локальный оркестратор агентных процессов (не IDE). Monorepo npm workspaces: `backend` (NestJS :3000, prefix `/api`), `frontend` (React/Vite :5173, proxy `/api`). Состояние: `backend/data/state.json` (`DATA_PATH`). Ветки: `dev` — разработка, `main` — стабильная.

Команды из корня: `npm run dev` | `npm test` | `npm run build`.

## Модули

### Корень
- `package.json` — workspaces, scripts `dev` / `test` / `build`
- `README.md` — продукт, Cursor CLI/API, env

## Связи

```
UI (pages → api.ts) → Nest controllers → services → StoreService (state.json)
                              ↓
                         RunsService / BoardService
                              ↓
                         orchestrator
                    ┌─────────┼─────────┐
              simulated   cursor-cli   cursor-client (API)
                              ↓
                    inspect/write project-folder (.pipil/карта.md)
```

- Один активный запуск процесса за раз.
- Доска → только simulated, даже если Cursor настроен.
- Пресеты (6 builtin: Фича, Тестирование, Рефакторинг, План, Баг, Вопрос) → открытие на холст → Workflow.
- Шаги: automatic | approval | question | ask | plan | build | review; граф через `nextIds`.
- Карта: читается в промпт/роль; дополнения ролей пишет оркестратор в конце; путь по умолчанию `.pipil/карта.md`.

## Владение

| Зона | Где править |
|------|-------------|
| Доменная модель / seed | `backend/src/domain.ts` |

| Persist | `backend/src/store/*` |
| HTTP контракты | `backend/src/**/*.controller.ts` + `frontend/src/api.ts` + `types.ts` |
| UI экраны | `frontend/src/pages/*` |
| Роутинг UI | `frontend/src/route.ts` |
| Доска (модель колонок) | `backend/src/board/model.ts` + `frontend/src/board.ts` |

## Как искать быстро

1. Контракт/тип → `domain.ts` (BE) / `types.ts` (FE)
2. Поведение запуска → `orchestrator.ts` + `runs.service.ts`
3. Cursor CLI/auth → `cursor-cli*.ts`, `settings/*`, FE `SettingsPage` / `cursor-cli-login-tab.ts`
4. Доска → `board/*` (BE+FE)
5. Холст/граф → `CanvasPage`, `step-graph.ts` (FE+BE)
6. Карта проекта → `project-folder.ts`, файл `.pipil/карта.md`
